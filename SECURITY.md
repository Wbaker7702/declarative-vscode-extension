# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Reporting a Vulnerability

We take the security of our software seriously. If you suspect that you have found a security vulnerability in this project, please report it to us immediately.

**Please do not open a public issue.**

Instead, please report the vulnerability by emailing [security@gradle.com](mailto:security@gradle.com).

Please include as much information as possible to help us understand and reproduce the issue. We will respond to your report as soon as possible.
